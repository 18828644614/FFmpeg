# 阶段 03：FFmpeg 基础

## 阶段目标

这一阶段建立 FFmpeg 的整体地图，能够用命令行查看媒体信息，理解容器、流、编码、数据包、帧和时间基，并为下一阶段的 C++ API 调用做好准备。

完成阶段后，你应该能回答：一个 MP4 里面有哪些流？压缩数据包和解码后的帧有什么区别？读取容器、解码、缩放、重采样分别由哪个组件负责？

## 学习顺序

按下面顺序进入主题。第一篇是组件地图，后面三篇分别把工具、文件结构和时间概念展开。

1. [ ] [[03-FFmpeg基础/FFmpeg组件概览]]：项目、工具、库、数据流和 Windows C++ 第一个实验
2. [ ] [[03-FFmpeg基础/FFmpeg命令行工具]]：`ffmpeg`、`ffprobe`、`ffplay` 的常用操作
3. [ ] [[03-FFmpeg基础/媒体文件与容器]]：容器、流、封装、元数据和格式选择
4. [ ] [[03-FFmpeg基础/时间戳与时间基]]：PTS、DTS、duration、时间换算和同步基础

## 阶段实践

- [ ] 使用 `ffprobe` 查看一个包含音频和视频的本地文件。
- [ ] 使用 `ffmpeg -f null -` 验证输入是否能被读取和处理。
- [ ] 编译并运行 [[03-FFmpeg基础/FFmpeg组件概览]] 中的 C++ 媒体信息查看器。
- [ ] 把同一个文件的 `ffprobe` 输出和 C++ 输出进行对照。
- [ ] 记录一次 DLL、路径或输入文件错误及排查过程。
